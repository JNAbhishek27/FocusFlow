# FocusFlow ⏱️ 📚

> **A full-stack study planner and Pomodoro productivity tracker built with Flutter & Serverpod 4.**  
> Created for **Build Something Real: The Serverpod Hackathon**.

---

## 🌟 Overview

**FocusFlow** is designed to eliminate academic fatigue, procrastination, and fragmented planning. Built as an end-to-end full-stack solution, FocusFlow marries structured coursework organization with active Pomodoro deep-work sessions and automated productivity analytics.

The frontend is powered by **Flutter** (Material 3 with responsive layout), while the backend is 100% built with **Serverpod 4** (using Serverpod ORM, endpoints, migrations, and code generation).

---

## ✨ Features

- 🏷️ **Curated Study Subjects**: Categorize courses and subjects with custom color tags and subject icons.
- 📋 **Prioritized Task Planner**: Plan study sessions with priorities (`urgent`, `high`, `medium`, `low`), time estimates, notes, and due dates.
- ⏱️ **Integrated Pomodoro Focus Timer**: Track active focus intervals with circular progress countdowns, reset controls, and custom presets (15m, 25m, 45m, 60m).
- ⭐ **Reflection & Rating System**: Rate session productivity on a 5-star scale with notes, and automatically auto-complete linked tasks upon save.
- 📊 **Real-time Analytics Dashboard**: Server-aggregated statistics computing:
  - Total study hours & minutes (all-time)
  - Daily focus time against a daily target
  - Tasks completed vs. pending
  - Average productivity score (5-star rating)
